# GPT娘额度挂件

这是本地插件的统一调用入口。用用户当前语言回应。

用户调用此入口且未指定其他任务时，使用本插件的 `get_codex_usage` 工具查询并简洁展示当前额度。先从可用工具中发现它；若工具不可用，如实说明插件连接尚未就绪。不要凭历史结果猜测当前额度。

此入口只查询额度。调整桌面挂件、开机启动或插件设置需要用户明确提出相应操作。
